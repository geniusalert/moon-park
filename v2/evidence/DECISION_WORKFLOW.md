## Issues found and corrected

- The guide initially received an entire scientific site object through its preview context and exceeded the service's request limit. Context now whitelists location identity and the current sky values. A regression test supplies very large terrain arrays and verifies they never enter the guide payload. The live Meta retest passed.
- A preview could retain old event/source text from the prior inspected site. V2 now hides those old readings until a calculated context is available, and the guide receives no displayed inspection for an uncalculated preview.
- Restored locations now populate the selector and review candidate rather than appearing as an empty selection.
- Long location names in the date grid received a dedicated sticky-width column and horizontal scrolling. Checkbox widths, named model-detail summaries, primary metric density and mobile clearance-value text were corrected during inspection.
