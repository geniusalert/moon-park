Then try your own coordinates

Install the optional terrain and ephemeris sources, select the 2027 calculation period, and enter any supported south-pole coordinate. Each point receives its own terrain and astronomical calculation. Missing coverage is rejected.

A passing visibility result is not landing-safety approval. These are finite-resolution terrain models, and new points have nominal results without calibrated uncertainty.
