# Navigator formative usability protocol

Status: Blocked — zero actual participant records. Automated and agent-driven checks are not human usability evidence.

Recruit five participants from the intended mixed audience. Obtain permission to record task results; anonymize as P1–P5. Give the same local release and no coaching. Record release/source identities, correctness, assistance, elapsed time and verbatim misconceptions for each task.

1. Select two locations and compare an arrival change.
2. Explain which selected visibility requirement fails.
3. Find an uninterrupted combined window long enough for the requested activity.
4. Choose a passing tested alternative and explain its ranking.
5. Identify terrain-resolution limits and explain what a passing result does not establish.

Target: at least four of five participants complete all five interpretation tasks correctly without assistance. Preserve unsuccessful observations. Fix material misunderstandings and record a separate follow-up rather than rewriting original results. If the target is missed, report it. Do not fill participant rows with generated or simulated responses.

Record format: participant alias, task number, expected interpretation, observed response, correct yes/no, assistance details, elapsed seconds, misconception, resulting fix, retest reference. Participant records are not bundled publicly by default.
