No records are sent to a server or retained by this page after it closes.

The proposed acceptance gate is at least four of five participants completing all five interpretation tasks correctly without coaching. Report actual scores, elapsed time, assistance and misunderstandings even if the target is missed. A five-person pilot supports formative interface findings, not general population claims. Repeat only after documenting the UI change; retain failed observations rather than replacing them.
